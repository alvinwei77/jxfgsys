# 废钢供应链信息系统（本地版 · 当前 v2.5.x）

轻量级本地 Web 系统，单用户使用，数据存储在本地 SQLite 文件中。对应《业务规则确认与计费模型 v0.2》文档的落地实现。

**日常菜单（v2.4.8 起）**：顶栏以 **车次 / 回款 / 统计** 为主；**规则与算价**（本期总览、费率、链条）和 **档案与系统**（档案、备份、术语；报价单在子菜单里、可忽略）收在下拉里。

## 一、如何运行

需要本机已安装 Python 3.9 及以上版本。

```bash
# 1. 进入项目目录
cd scrapmetal

# 2. 安装依赖（只需第一次执行）
pip install -r requirements.txt

# 3. 初始化数据库（只需第一次执行；如果 data/scrapmetal.db 已存在则不会覆盖，
#    如需重新初始化请先删除 data/scrapmetal.db 再执行本步）
python init_db.py

# 4.（可选，仅第一次）导入您提供的台账 Excel 历史数据 + 华西特钢报价单品类
python imports/import_data.py "/path/to/8.19付款明细-欧冶物宝1.xlsx"

# 5. 启动服务
python app.py
```

启动后浏览器访问 `http://127.0.0.1:5000` 即可使用。数据全部保存在 `data/scrapmetal.db` 这一个文件里，**建议定期复制这个文件做备份**（比如每天收工后复制一份改名加日期）。

停止服务：回到运行 `python app.py` 的终端窗口，按 `Ctrl+C`。

## 二、已实现的功能

- **首页看板**：今日接单、本结算周期(26日-次25日)送货吨位、待结算车次、本周期已结算车次、本周期利润估算、票源额度提醒。
- **车次管理**：新建/编辑车次，状态流转（待报备→已报备→在途→已到厂→已过毛磅→已过皮磅→已结算→已开票→已回款→已结案，支持点击任意状态直接跳转、推进/回退、克隆此车、作废）、导出CSV（可用Excel直接打开）、多条件筛选（状态/钢厂/供货厂/车船类型/日期区间/车号搜索）。
- **车次详情**：…、付款记录、**附件可上传**（过磅单/结算单，含手机拍照）。
- **基础档案**：钢厂、钢厂量补阶梯规则、户头（钢厂×国企组合，国企可留空）、国企/垫资方、加工基地、调货人、前端公司/反向自然人（含点位、额度）、车辆/船舶、司机、货型字典，均支持增删改查。
- **报价单**：按钢厂、按期号管理，自动对比上一期涨跌，页脚可维护全局规则说明（量补规则、合规要求等）。
- 已导入您提供的台账 Excel（8.19付款明细-欧冶物宝1.xlsx）中 75 条历史车次数据（作为已固化快照导入，净利润总额与原表完全一致：107,778.82元），以及华西特钢 2026-09-12 期报价单的全部23个货型价格（含9.11前期价格用于涨跌对比）。

## 三、量补/计费模型说明（与您确认的口径一致）

- 量补奖励按"钢厂 + 结算周期(26日-次25日)"维度，在该钢厂当期累计结算吨位，全额累进定档（阶梯在"基础档案-钢厂量补规则"中配置，华西特钢已预置 3000吨→20元/吨、5000吨→25元/吨）。
- 车次结算模式 M1~M5（M1自营带票 / M2外部直签带票 / M3外部不带票走户头通道 / M4调货人对接 / M5反向自然人开票）对应两套计费公式，详见《业务规则确认与计费模型 v0.2》文档第二节。您确认过"暂按此执行，后续再优化调整"。
- 历史台账数据的计费口径（混合折算系数）与新系统的"货差+票差"拆分口径不完全一致，导入时做了忠实换算，保证净利润数字和原台账一致，但"货差利润"字段里实际装的是原表的综合系数金额，请知悉（详见 `imports/import_data.py` 文件头部注释）。

## 四、已知限制 / 建议后续迭代

1. ~~附件上传~~ **已实现**（车次详情 + 手机 `/m`）。

## 五、目录结构（v2.0.1）

```
scrapmetal/
  app.py              启动入口（双击「启动系统.command」即运行它）
  core.py             Flask 实例、常量、共用工具函数
  routes_*.py         各功能的页面/接口：pages 页面与出错页、archives 档案与费率、rules 链条规则、
                      trips 车次、quotes 报价单、reports 看板/统计/预警/导入/导出
  lanes.py            三条线 / 批次 / 回款追踪
  system_ops.py       备份、操作记录、回收站、版本号与一键重启
  regression.py       利润自动核对（regression_check.py 为命令行版）
  engine.py           计算引擎（链条规则 → 每车利润）
  calc.py             引擎共用的小工具（结算周期、量补阶梯、点位）
  ledger_export.py    一键导出台账
  VERSION             版本号
  legacy/             已下线的旧代码，仅作历史对照（旧计算引擎、拆分前的 app.py）
  db.py / init_db.py / schema.sql   数据库
  templates/ static/  页面模板、样式与前端脚本
  data/scrapmetal.db  数据库；data/backups/ 自动/手动备份
```
