系统里有些词是行业黑话、有些是别处叫惯了的名字，对不上。这一页把「你可能怎么叫 / 系统里叫什么 / 在哪」摆在一起。 各个页面上的虚线下划线也可以直接把鼠标放上去看解释。
一、常见事情怎么做
你想做的事怎么操作说明 / 备注
录一车货首页「新建车次」，或车次管理页「+ 新建车次」填上车牌，其余按这个车牌的历史自动带出；带不出的（每次都不一样的）留空让你手选。
一次录一批（按钢厂结算单）车次管理页 →「批量录入（粘贴·自动认列）」从 Excel / 结算单整块复制粘贴，系统自动认出每列是什么；认错了可以逐个下拉改。按车号+日期匹配已有车次，找不到的自动新建并推进到「已结算」。列的含义见本页第三节。
把车往前推一步车次行右侧的「→下一状态」按钮状态顺序：已报备 → 已到厂 → 已结算 → 已开票 → 已结案。点的时候会自动填上对应日期（已有日期不覆盖）。
一次推多车勾选车次 → 上方「批量推进到…」可以一次录多车的结算吨位/金额：从 Excel 复制「吨位、金额」两列，粘到第一行吨位框里会自动铺开。
录磅重明细（一车多料）点车次行 → 先看「车次明细」抽屉；要改就进「详情」→「磅重与结算」一车装好几种货型就加几行。净重/结算吨数/金额留空会按 毛重−皮重、净重−扣杂、吨数×单价−切割费 自动算。
改某一车的费率（只影响这一车）车次详情 →「利润分项」右下「本车费率」填了就覆盖档案里的值，清空恢复默认。改的是这一车，不动档案、不影响别的车。
把这一车的利润定下来车次详情 →「固化快照」固化后档案费率以后再改，这一车的数字也不跟着变。对账、月结之前建议固化。
登记开票 / 回款批次回款追踪页一批可以挂多车。首页「资金占用与待办」点进去就是对应的待办车次。
看某家票源额度用了多少首页看板 →「票源额度水位」点票源名字，直接跳到占用它额度的那些车。
导出给领导看的报告首页 / 统计报表 →「导出经营报告 PDF」要 Excel（分期与专题，多个 sheet）用「导出经营报告 Excel」。也可以先点「在线预览」看看再导。
导出台账车次管理页 →「导出台账」一个文件三个 sheet：车次明细 + 磅重明细 + 统计汇总。要当前筛选结果用「导出CSV」。
录错的车次想删掉点车次行 → 明细抽屉底部「删除」；或车次详情右上「删除」删除是进回收站，30 天内能在「系统 → 回收站」按原编号恢复。
不想让它算钱、但要留个记录车次详情 →「作废」作废的车不计入任何统计，但仍留在列表里（标红），不进回收站。
改外部费率 / 点位 / 额度费率与关系页系统按「关旧行 + 开新行」记录，改完之后历史车次按旧值算、新车次按新值算，不会把过去改掉。
改链条的计算口径链条规则页 →「编辑」→ 计算公式保存前会先算一遍"改了之后哪些车、差多少钱"，确认才写库。只影响以后新算的钱，已固化的历史车次不变。
调提醒阈值（几天算超期、额度到几成预警…）系统页 →「参数设置」票源额度预警线、报备超期天数、开票/回款超期天数、账龄分档、车牌自动带出门槛、备份保留份数、回收站天数等。
看不懂某个词本页；或把鼠标停在页面上带虚线下划线的词上同一个词全站一套说法，不会再出现五个页面五种叫法。

三、术语一句话解释
术语一句话解释涉及页面
结算期每月 26 日 ~ 次月 25 日算一个结算期（期号形如 2026-10期）。量补档次、月度票额都按这个窗口算，不是自然月。首页、统计报表、经营报告
票源额度这家票源方在我们这边最多能开多少票（金额）。配票按月度额度（结算期），反向按年度额度（自然年）。基础档案 → 票源额度分期；首页水位
水位额度已经用掉多少的进度条。到预警线转黄、超过 100% 转红。首页「票源额度水位」
配票（M1）用我方的票源方额度开票，赚差价；占月度票额。链条规则、车次详情
反向（M5）票源是自然人、反向开票；占年度票额。链条规则、车次详情
自带票（M2~M4）又叫直签带票：供货方自己有票、自己开，我方只做通道/服务，不占我方票额，只看"票面额 = 含税结算额"。首页水位 B 区、经营报告 B 区
链条规则一车货从供货厂到钢厂走的那条业务链——谁开票、谁垫资、谁付款。车次选了哪条链条，就算哪套钱。链条规则页
节点 / 计算口径链条规则里一个"算钱的口子"（例如"给客户付"按对外点位算）。改节点就是改这条链的计算口径。链条规则 → 编辑 → 计算公式
垫资费我们先把钱垫给供货厂、等国企或钢厂回款才收回来，这段占用资金的成本，按 元/吨 计。费率与关系、车次详情利润分项
票差留存利润经过我方票源方开票才有的一段差额（转出点位 − 进项点位），单独留存，不计入净利润。车次详情、经营报告
固化 / 固化快照把这一车当前的利润数字存下来。固化后档案费率再改，这一车的数字也不跟着变。车次详情「固化快照」
利润估算已固化的车次取固化快照，没固化的按当前档案参数实时算——所以它只是估算，不是最终会计数。全站汇总数字
应收应付基准按链条规则自动算出来的"这车该收多少、该付多少"，用来跟实际开票/打款核对，两者不互相推算。车次详情「发票/打款核对」
账龄这笔待办从起算日（开票看结算日、回款看开票日）到现在过了多少天，用来盯超期。首页资金占用、回款追踪
混料一车里装了好几种货型、拆不开，以钢厂结算单的合计为准。车次详情
扣杂钢厂验货时按杂质比例扣掉的吨位，扣完剩下的才是结算吨位。车次明细、统计报表·质量
票面额发票上的含税金额。自带票的票面额 = 含税结算额，不减垫资费。首页水位 B 区、经营报告
车牌画像这个车牌历史上常走谁家的货、用哪条链条。输入车牌后按历史自动带出（同一取值达到"稳定门槛"才带），变来变去的字段不猜、留给你选。车次管理录入时
录入默认值新建车次时自动填的东西：发货地、只有一个钢厂时的钢厂和户头、接单日期今天。车次管理页「默认值」
回收站删除的车次/档案先放这里，30 天内可按原编号恢复，过期自动清理。作废的车次不在回收站，它还留在列表里。系统 → 回收站
操作记录（audit）每一次修改都记下来：什么时间、改的哪一条、从什么改成什么。系统 → 操作记录
四、批量录入的列是什么意思
表头含义
日期优先当结算日期用；没有单独结算日期时也当接单日期匹配车次。
车牌 / 车号匹配已有车次的钥匙（车号 + 日期 ±3 天）。匹配不上就自动新建一车。
货型用简称也能认（如"剪中1"= 剪切中废1）。
扣杂(吨)钢厂扣掉的杂质吨位。
结算吨位钢厂认账的吨位。系统会用「吨位 × 单价 ≈ 金额（±2%）」反过来校验，认错了会换一列。
单价结算单价（元/吨）。
切割费单独的加工/切割费用。金额与「吨位×单价」的差正好等于它时，系统会认成切割费而不是算进单价。
金额含税结算金额。一般 = 结算吨位 × 单价（再加切割费）。
结算单号同一张结算单的多车填同一个号。
票源 / 调货人决定这车走哪条链条：俊兴/煌烽/益周=配票；"反向-XX"=反向；自带票公司=自带票。
单独一行的「/」表示和上一行是同一车（一车多料），系统会合成一车两条明细。
粘贴进去之后，每一列认成什么都可以在下拉里改；右下角「按车号+日期匹配」的结果也会先预览一遍，确认了才写库（写库前自动备份）。
